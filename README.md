# Analytics Portfolio Demo

A lightweight portfolio demo centered on an e-commerce SQL case study and a concise project overview.

[Open the live GitHub Pages demo](https://amitkumardata.github.io/My-First-Repository/)

## Case study: e-commerce platform

[E-Commerce_Project.sql](./E-Commerce_Project.sql) explores business questions across orders, payments, products, sellers, and customer reviews:

- How total payment value changes over time.
- Which product categories lead on units and sales.
- Average order value by payment method.
- Active seller counts by month.
- Review score compared with order volume and average product price.

The queries use joins, aggregation, grouping, date functions, ordering, and a window-function example. The SQL file references tables in the project_placement schema; source data is not stored in this repository.

## What to review

- Read the question comments in the SQL file before reviewing each query.
- Check how joins connect orders, payments, products, sellers, and reviews.
- Adapt date functions to the SQL engine used for execution.
- Treat the result as a query portfolio, not a production application.
